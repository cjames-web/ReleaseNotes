Bug Fixes

Bug Fix Removed Page Swipe Navigation

The ability to swipe between pages of the form has been disabled. This feature contained an unintended bug that allowed users to submit a form without stepping through each required process step. As a result, forms could be sent without being recorded to the associated spreadsheets, leading to lost production data and operational delays.

Affected Glo Form Space SPLICE POINT Form

Summary of Changes

Category Description
Bug Fix Disabled swipe-to-navigate between form pages to prevent accidental out-of-order submissions.
Data Integrity Ensures all form submissions are properly routed to the associated spreadsheets without data loss.
Workflow Users must now step through each required process step in order before a form can be submitted.
